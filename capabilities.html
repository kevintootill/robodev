01
THE FIRST LINE

Make the blank page smaller.

Turn a goal into a clear starting point. Break a feature into parts, establish a structure and decide what needs to happen first.

  • Clarify requirements and constraints
  • Explore implementation options
  • Review the proposed structure before building
02
THE BETTER VERSION

Untangle. Simplify. Make room.

Understand the behaviour you need to preserve, then make the code easier to follow and change.

  • Identify repetition and unnecessary complexity
  • Improve names and boundaries
  • Verify that behaviour stays consistent
03
THE MISSING CONNECTION

Find the why. Fix the what.

Bring the error and its context. Trace the path to the failure, test the explanation and make a focused repair.

  • Reproduce the issue
  • Follow the evidence to the cause
  • Check the fix against the original failure
